# 🧠 VirtualVeins - Social Media Mental Health Research Dashboard

> **Interactive React dashboard analyzing social media impact on mental health**

[![React](https://img.shields.io/badge/React-18.2.0-blue.svg)](https://reactjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.3.2-38B2AC.svg)](https://tailwindcss.com/)

##  Project Overview

VirtualVeins is a comprehensive research project with an interactive React dashboard that visualizes findings from 481 survey respondents on social media's impact on mental health.

### Key Statistics
- **481 Survey Respondents**
- **6 Social Media Platforms** analyzed
- **73%** report mental health impact
- **4.2 hours** average daily usage

## 🚀 Quick Start

```bash
git clone https://github.com/GarvitGoel04/VirtualVeins.git
cd VirtualVeins
npm install
npm start
```

## 🛠️ Tech Stack

- **React 18** - Frontend framework
- **Tailwind CSS** - Styling
- **Recharts** - Data visualization
- **Framer Motion** - Animations
