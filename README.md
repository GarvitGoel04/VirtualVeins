# VirtualVeins - Social Media Mental Health Research Dashboard

A comprehensive research project analyzing the impact of social media on mental health, presented through an interactive web dashboard.

## 🧠 Project Overview

VirtualVeins is a data-driven research initiative that investigates the correlation between social media usage patterns and mental health outcomes. The project includes:

- **481 Survey Respondents** across diverse demographics
- **20 Comprehensive Questions** covering usage patterns and mental health metrics
- **6 Social Media Platforms** analyzed for platform-specific impacts
- **15 Mental Health Metrics** including depression, anxiety, and sleep patterns
- **Advanced Statistical Analysis** with correlation studies and predictive modeling

## 🚀 Features

### Interactive Dashboard
- **Real-time Analytics**: Live data visualization with interactive charts
- **Key Metrics Display**: Important statistics and findings at a glance
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices

### Data Analysis
- **Age Distribution Analysis**: Understanding demographic patterns
- **Gender-based Insights**: Comparative analysis across gender groups
- **Platform Impact Study**: How different social media platforms affect mental health
- **Usage Pattern Correlation**: Relationship between usage time and mental health impact

### Research Documentation
- **Methodology Overview**: Detailed research approach and data collection methods
- **Key Findings**: Comprehensive analysis of survey results
- **Implications**: Real-world applications and policy recommendations
- **Academic Publications**: Research papers and conference presentations

## 📊 Key Findings

- **73%** of users report mental health impact from social media
- **4.2 hours** average daily social media usage
- **68%** experience distraction during other activities
- **82%** seek validation through social media platforms
- **59%** report sleep issues related to usage

## 🚀 Getting Started

### Prerequisites
- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd VirtualVeins
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the application

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

# Virtual Veins

**"Impact of Social Media on Human Cognition and Behaviour"**  
A final year B.Tech project under the Department of Computer Science & Design, IMS Engineering College.

## 🧠 Overview

Virtual Veins is an academic research and data analysis project aimed at exploring how prolonged usage of social media influences human cognition, behavior, and emotional well-being. The project combines psychological insights, data collection, and analytical tools to derive meaningful conclusions.

## 🎯 Objectives

- To study the cognitive and behavioral impact of major social media platforms.
- To conduct surveys and analyze user data for sentiment patterns.
- To explore how social media affects attention span, memory, and mental health.
- To propose possible solutions or design interventions to mitigate negative effects.

## 🛠️ Technologies Used

- Python (for data analysis and scripting)
- Jupyter Notebook (`.ipynb` for visualizations)
- Pandas, NumPy (data handling)
- Scipy for ANOVA test and Others statistics 
- Matplotlib, Seaborn (data visualization)
- Excel & CSV (survey data collection)
- Git for version control
